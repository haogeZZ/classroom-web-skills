# PPT 网页课件

使用原 PPT 作放映依据，在浏览器上课。普通展示页优先保留原画面，互动由逐页需求决定。显式调用为 $ppt-web-classroom。

## 从 Word 模板接单

收到《课堂联动与网页课件需求填写模板》时，按首页勾选项读取。读取旧版 .doc 时，必要时先在工作目录转换为 .docx，再按表格读取，保留原文件。名称改变时按字段编号识别。用户也可以直接发 PPT 和想法，由本技能按相同字段起草。

| 字段 | 如何使用 |
| --- | --- |
| B1 | 确认 PPT 原稿，采集原页码、画幅、隐藏页、媒体及原文字。 |
| B2 | 将现成网页、视频和资源分配到页面。填「接本表 A」时引用同一份表中 A 表生成的课堂应用。 |
| B3 | 一行对应一处要处理的 PPT 原页。记录保留或替换区域、首屏、每次前进动作、落点、嵌入来源和重入状态。其余页按原放映顺序处理。 |
| B4 | 记录隐藏页、页序、媒体和重入状态的覆盖规则。 |
| C1 | 记录已批准原文的出处和准确新增、替换、删除位置与文字。 |
| C2 | 「先整理需求」、空白或选择不清时先交需求。明确选「可以开始生成」、关键需求齐备且所需新增界面原文已确认时，可按表直接生成。 |

按附件指定位置提取可确定的内容，集中追问会影响上课和验收的缺项。确认前保存需求与逐页表。修改先更新需求记录，要求明确的删除直接按指定位置记录并执行。新增可见标题、按钮、提示、备注、状态等须先获得逐字确认；沿用已明确批准的原文。课堂界面各入口删除标记材料为样本的可见文字，保持功能与真实来源。

## 制作课件

1. 用原文件核对页码和画面。普通页优先渲染原稿，保持画幅、页面顺序和版式，默认遵循原有隐藏页设置。视频与页内显现按逐页表实现，确认媒体可用及其播放、停止或末帧行为。
2. 复用已验证的浏览器放映器和素材组织方式。统一放映位置与页内步骤，核对键盘、翻页笔、全屏和批注。输入框、画布和嵌入页操作要与课件步进正确配合。记录嵌入的尺寸、位置、焦点与加载依赖。
3. 在课件内处理点击显现、独立互动和媒体。多设备扫码、发任务、作品回收与实时巡看由 $lan-teaching-dual-client 处理。合用时先确认两份需求，先接通课堂再绑定网页课件。嵌入课堂页面复用同一课堂、授权与现有入口，避免打开互不相通的课堂。普通独立网页可直接接入。
4. 默认返回时，课件自身的讲解动画和视频从头开始，课堂草稿、作品和教师巡看继续使用当前课堂状态。个别页按 B3/B4 覆盖。切页和重入时核对事件、播放和会话状态。
5. 交付本地网页版课件、所需资源、放映入口、启动方法和实测记录。逐页和原 PPT 对照，核对全屏与缩放、视频、页内推进、前后翻页、焦点、互动和返回状态。组合项目从一台学生设备操作到课件大屏查看，确认处于同一课堂。公开仓库和公网发布须有后续明确授权。

## 沿用旧界面

取得有权使用的上一版源文件或界面截图。对齐原 PPT 的画幅、字体、配色、放映工具位置及互动嵌入区域。逐页表中写清换哪些素材、每次翻页先触发什么、哪些课堂状态应当恢复。优先复用已确认的放映器样式。
