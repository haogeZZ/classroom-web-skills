# Word 填写模板和课堂联动

《课堂联动与网页课件需求填写模板》版本 1.0 可由用户填写或由技能根据教案与截图先填。改名后可用表内字段编号识别。读取旧版 .doc 时，必要时先在工作目录转为 .docx，按表格读取，保留原文件。

| 字段 | 生成时的用途 |
| --- | --- |
| A1 | 从课题、年级和目标明确学生应完成的课堂作品。 |
| A2 | 确定教师电脑、终端和分组，未指定部署时采用教师电脑开局域网服务。公网按明确需求启动分支。 |
| A3 | 每项任务对照材料、交互、完成条件和提交内容。操作区按该课设计，复用扫码、任务发布、提交与同步。 |
| A4 | 写明哪些未提交的课堂操作要实时可见，独立大屏要显示实时巡看、已交作品或两种。可进一步指定轮播布局、节奏和选组。 |
| A5 | 找课件、附件和已有项目；修改时定位实际使用版本并先记录变更。 |
| C1 | 使用已批准原文或原文出处。新增和替换先确认准确原文，删除按明确位置记录后执行。 |
| C2 | 「先整理需求」、空白或选择不清时先交需求。明确选「可以开始生成」、关键需求齐备且所需新增界面原文已确认时，按表直接生成。 |

明确写「从附件提取」时读取指定附件。对能从材料确定的字段直接填入。缺失且会影响任务、操作、展示或验收的字段，集中提问。确认后在项目保存需求与界面原文。只勾选 A 时处理课堂；同时勾选 B 时，在确认两份需求后先做同一课堂的可运行入口，再让 $ppt-web-classroom 绑定需要的学生端或大屏。

## 实时巡看和独立大屏

- 新课沿用扫码领组号和同源恢复规则。教师统一发布任务。切换前列出当前任务参与组中仍未提交且尚未获准跳过的组，允许补交或由教师确认跳过。待处理组清零后由教师发起切换，所有学生端同步。已交作品和草稿按该课规则保留。
- 只同步确认范围内的课堂网页状态。任务切换、未闭合的草稿、拖动和输入按需同步。提交前的状态随课堂会话更新，默认不生成持久化课后回放。正式提交进入作品库。
- 独立大屏接收教师端的展示选择、暂停、继续和切换。教师巡看与投给全班的画面分别控制。已交作品和进行中的小组是不同数据来源，轮播范围按 A4 确定。能在教师端、独立大屏或课件嵌入中复用展示视图。
- 交付前检查扫码重进、教师发布、学生补交与教师跳过、统一切换、未提交操作实时显示、提交保存、大屏控制、离线与重连。大屏和课件嵌入所用课堂身份须与学生真实进入的课堂一致。
