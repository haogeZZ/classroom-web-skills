# 课堂联动与网页课件 Codex Skills

把教案、原 PPT、界面参考和一张需求表交给 Codex，用于制作平板学生端、教师端、轮播大屏，或把指定网页接入浏览器课件。两个 Skill 可以分别用，也可以接力。

| 需要制作 | 需求表 | 调用 |
| --- | --- | --- |
| 扫码进班、教师发任务、作品提交、实时巡看与轮播 | A 表和 C 表 | $lan-teaching-dual-client |
| 保留原 PPT 画面，在指定页加入网页互动 | B 表和 C 表 | $ppt-web-classroom |
| 在课件内打开学生端或大屏 | A、B、C 三表。B2 写「接本表 A」 | 先做课堂联动，再接入课件 |

下载 [Word 需求模板](templates/课堂联动与网页课件需求填写模板.doc)，在 WPS 或 Word 中填写。把 Word 和所需材料交给 Codex。有教案、截图或原 PPT 时，也可以让 Codex 先根据附件填表。关键材料齐备后，在 C 表确认新增界面的准确文字并选择「可以开始生成」。

## 在 Codex 中使用

1. 下载仓库。将 [skills](skills) 中要使用的 Skill 文件夹放进自己的 Codex skills 目录，保留其中的 SKILL.md 和 references 子目录。Codex 默认本机目录为 ~/.codex/skills。配置了 CODEX_HOME 时，使用其 skills 子目录。
2. 在新对话中调用对应的 Skill，并附上填写好的需求表和材料。已有同名 Skill 的用户可以继续使用自己的版本，或按需更新。
3. 同时制作两套时，先确认课堂应用的学生、教师和大屏入口，再按 B 表逐页接入。完成后，在实际平板和投影尺寸上检查。

## 如何做出同款界面

先打开[课堂网页元素设计规格](visual-style.md)，按本课需要的页面选用：

| 要做的页面 | 可直接对照的设计元素 |
| --- | --- |
| 学生端 | 左侧操作画布、右侧记录表、点线图例、记录行、数值输入、新建与提交 |
| 教师端 | 页头、阶段页签、组号列表、作品与记录、任务发布、放大弹窗、大屏控制 |
| 独立大屏 | 一大三小、主图与正文、作品编号、缩略卡、切组、暂停、离线与恢复 |
| PPT 网页放映器 | 16:9 舞台、底栏和图标、画笔、视频播放器、翻页步进与局部嵌入 |

规格按元素列出已核对的颜色、尺寸、间距、位置和触发状态。发给 Codex 时，把希望沿用的页面写在 Word A5 或 B2。需要调整的元素用规格末尾的表逐行填写，新增或替换的原文记入 C1。

| 你要提供 | 在哪儿写 | 制作时据此确定 |
| --- | --- | --- |
| 一套可复用的旧项目源码，或有权使用的原界面截图和短录屏 | A5 或 B2 | 指出沿用的学生端、教师端、大屏或放映工具栏 |
| 每个目标端的完整截图、设备方向和比例 | A5 或 B3 | 对齐布局比例、字号、主题色、留白和控件位置 |
| 本课地图、题目、图片、PPT 及每步操作 | A3 或 B3 | 更换课题内容，定义拖拽、画图、提交、切换或翻页 |
| 逐字确认的标题、按钮和提示 | C1 | 沿用批准原文或按你填写的文字更新 |
| 大屏给全班看什么 | A4 | 选择实时操作或已交作品，以及大图、缩略图和切换方式 |

有旧源码时，指出正式版本或提交号，优先复用已有页面与样式。只有截图时，至少准备一张首屏和每个关键状态的截图，例如操作中、提交后、等待和断线恢复。若要沿用「一大三小」大屏，说明大图显示哪些内容、小图如何排序、何时自动切换、教师在哪里暂停。

可以把下面这段话和附件一起发给 Codex：

> 按附上的上一版页面做同款。沿用截图中的布局、颜色、字号、控件位置和 C1 已批准原文。学生这次完成 A3 的任务，大屏按 A4 展示。B 表里指定的网页从相应 PPT 页打开。请先把你能从附件确认的要求写进需求记录。

## 仓库内容

- 两套 Codex 工作流、课堂网页元素设计规格和可编辑 Word 表格。
- 课堂联动覆盖扫码恢复、任务切换、作品提交、实时巡看及教师控制的大屏。
- 网页课件覆盖原 PPT 逐页处理、媒体、互动步进和课堂接入。

界面以你提供的可复用源码或参考图为依据，学生操作区按本课任务制作。仓库提供需求入口与制作流程，实际课件及课堂页面由 Codex 根据你的材料生成。
